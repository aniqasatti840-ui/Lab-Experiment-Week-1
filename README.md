# OOP Lab Manual

## Week 01

### Experiment 01: Student Structure

Write a program that declares a structure based on the following entity shown in the box. The program must declare and initialize an instance of the structure entity i.e. **Student**.

The attributes of the entity are:

- `studentID` (integer)
- `studentName` (char*)
- `courseCode` (char*)
- `courseName` (char*)
- `courseMarks` (integer)

---

### Experiment 02: Date Structure

Create a structure of type **Date** that contains three members:

- Month (int)
- Day (int)
- Year (int)

Have the user enter a date in the format:

```text
12/31/2001
```

Store it in a variable of type `struct Date`, then retrieve the values from the variable and print them out in the same format.

---

### Experiment 03: Employee Structure

Create a structure called **Employee** that contains two members:

- Employee Number (int)
- Employee Compensation (float)

Requirements:

1. Ask the user to enter data for three employees.
2. Store the information in three variables of type `struct Employee`.
3. Use a separate display function to show employee information.
4. Display the information for all employees.

---

## Learning Objectives

After completing these experiments, students will be able to:

- Understand the concept of structures in C++.
- Create and initialize structure variables.
- Store and retrieve data using structures.
- Use functions with structures.
- Organize related data using user-defined data types.
